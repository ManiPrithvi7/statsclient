guide:

1. Open the Command Line: Press the Windows key, type "Command Prompt", and open the program.

2. Clone the Project: In the Command Prompt, type the following command and press Enter:

git clone git@github.com:ManiPrithvi7/statsclient.git
 
** This will download the project files to your computer.

3. Enter the Project Folder: Type the next command and press Enter:

cd statsclient

4. Run the Setup Script: Finally, type the last command and press Enter:

run.bat

Follow the on-screen prompts. The script will check for required software (like Python, Git, and ESP-IDF) and guide you to the correct download pages if anything is missing.
